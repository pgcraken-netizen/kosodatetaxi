# 子育てタクシー 利用者管理システム

フォーム回答（Excel / CSV）を読み込み、出産予定リストの作成・並び替え・Excel出力を行う静的Webアプリ（`src/index.html` 単体）。

- お客様情報はブラウザのメモリ上のみで処理（サーバー保存・送信なし）
- 申し送り・医療機関マスタ・地図の位置キャッシュは端末の localStorage に保存（利用者とはハッシュ化した識別キーで紐付け）
- 地図：Leaflet＋国土地理院タイル（遅延読み込み）。「位置情報を取得」押下時のみ住所を国土地理院 住所検索API へ送信
- デプロイ：Vercel（プロジェクト kosodatetaxi-h2zw、ルート `src`）

`src/logo.png` はデザイン画像から切り出した仮ロゴです。正式な背景透過PNG/SVGに差し替えてください。
